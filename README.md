# ヨハク / YOHAKU

**悩みと自分のあいだに、すこし距離をつくるための道具です。**

ハッカソンテーマ「顔を知るたった一人の悩みを突き刺せ」への回答としてつくりました。

## これは何か

悩みを「解決」しません。**ほどいて、並べて、原因までたどって、他人の話として観せる**ところで終わります。

書かれたものを次の三つに切り分けます。

| | 分類 | 定義 |
|---|---|---|
| 事 | **事実** | 相手が言ったこと、した行動、周りの反応。録画に残るもの。 |
| 想 | **想像** | まだ確かめていないこと。相手の内心、これから起きること。 |
| 情 | **感情** | そのとき自分が感じたこと。正しいも間違いもないもの。 |

自分の悩みは近すぎて形が見えません。分けてしまえば、量の偏りとして目に見えます。

## なぜこの解釈にしたか

「たった一人の悩み」にフォーカスするほど、悩みは内面的・精神的なものになります。そして内面的な悩みには共通の性質がありました。

- **すぐには解決できない** — すぐ解決できる悩みは、そもそも一人で抱え込まない
- **本人は解決策を求めていない** — 求めているのは「ぐちゃぐちゃした思考をクリアにすること」
- **その悩みを知っているのは、相談された人か本人だけ**
- **そもそも相談しない人がいる**

だから「共感してくれるAI相談相手」をつくる道は捨てました。他人（AIを含む）から与えられた共感は、本人が信じられないからです。代わりに、**本人が書いた言葉だけを材料にして、本人に見せる**構造にしました。

## 6つのステップ

1. **書き出す** — 4つの質問に沿って書く。詰まったときの手がかりタグつき（自由記述にも切替可）
2. **仕分ける** — 自動で一文ずつのカードに切り分け、三分類へ。誤分類はその場で差し戻される
3. **並べる** — 比率と内訳を表示。「頭を占めているものの58%は、まだ確かめていないことでした」
4. **たどる** — いちばん重い一枚 → きっかけの事実 → なぜそう思ったか → 何を失うと思ったか。因果の一本線として表示
5. **観る** — 整理した内容を三人称の短編として上映。主人公は「その人」。最後に「この話のその人は、あなたです」
6. **置いていく** — 持ち帰りカード（コピー可）

## 設計で決めた三つのこと

- **助言をしない** — 「こうしたら」を言った瞬間、これは相談窓口になる
- **原因まではたどる** — ただ分類して終わりにしない。「なぜ」を二段だけ掘り、そこで止める
- **誰にも送らない** — 相談しない人が使えるように、送信先を持たない

## 分類のルール（実装されているガード）

事実に置けるのは、外から観測できたことだけです。次の場合は事実ボタンを押しても差し戻されます。

- **曖昧表現の検知** — 「かもしれない／気がする／たぶん／このままだと／思われる」等を含む文
  → 想像に置く／確かめられる形に書き直す／相手が言った言葉なので事実、の3択
- **感情語の検知** — 「怖い／恥ずかしい／情けない」等を含む文
  → 自分の気持ちなら感情へ。相手の様子として見えたこと（例:「部長が怒っていた」）なら事実のまま

## 動かし方

### ローカルで開く

`index.html` をブラウザで開くだけです。ビルドもサーバーも不要です。

```bash
git clone https://github.com/USERNAME/yohaku.git
cd yohaku
open index.html          # macOS
# start index.html       # Windows
# xdg-open index.html    # Linux
```

### GitHub Pages で公開する

`SETUP.md` に手順があります。

## 技術

- **依存ライブラリ ゼロ**。単一のHTMLファイル（HTML + CSS + Vanilla JS）
- 外部通信は Google Fonts（Shippori Mincho / Zen Kaku Gothic New）のみ
- 上映の読み上げに **Web Speech API**（`speechSynthesis`）。使えない環境では字幕のみで再生されます
- 入力の下書きは `localStorage` に保存。**サーバーには何も送信しません**
- ライト／ダークの両テーマに対応

### 動作環境

- Chrome / Edge 推奨（読み上げ音声の対応が最も安定しています）
- Safari / Firefox でも動きますが、音声の声質や有無が環境に依存します
- Web Speech API は https または localhost でのみ動作します（GitHub Pages は https なので問題ありません）

## プライバシー

書かれた内容がこの端末のブラウザの外に出ることはありません。分析ツールも、サーバーも、送信ボタンもありません。
